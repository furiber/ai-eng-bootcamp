# Ask API

A small FastAPI service with one endpoint, `POST /api/ask`, that forwards a question
to an OpenAI model and returns the answer. A static single-page frontend is served
from the same app, so there is one container and no CORS configuration.

| Path            | What it is                                     |
| --------------- | ---------------------------------------------- |
| `/`             | Frontend page that calls the API                |
| `/api/ask`      | The endpoint (POST JSON)                        |
| `/health`       | Liveness probe, used by Render's health check   |
| `/docs`         | Swagger UI (generated by FastAPI)               |
| `/redoc`        | ReDoc, same schema                              |
| `/openapi.json` | The OpenAPI schema itself                       |

## Run locally

```bash
cp .env.example .env          # then put your key in OPENAI_API_KEY
pip install -r requirements.txt
uvicorn main:app --reload
```

Open <http://127.0.0.1:8000/> for the frontend or <http://127.0.0.1:8000/docs> for Swagger UI.

Example request:

```bash
curl -X POST http://127.0.0.1:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "Why is the sky blue?", "model": "gpt-4o-mini"}'
```

## Run the checks

```bash
python test_main.py
```

The OpenAI call is stubbed, so no key or network access is required.

## Run the container

```bash
docker build -t ask-api .
docker run --rm -p 10000:10000 --env-file .env ask-api
```

Then open <http://localhost:10000/>.

## Deploy to Render

`render.yaml` defines a Docker web service. Push this repo to GitHub, then in Render
choose **New → Blueprint** and point it at the repo. Render will prompt for
`OPENAI_API_KEY` on the first deploy (it is marked `sync: false`, so the value never
lives in the repo).

The container binds to `0.0.0.0` on `$PORT`, which Render requires. `DEFAULT_MODEL`
sets the model used when a request does not specify one.
